### Profiles

| Column | SQL type | Required/default | Rule |
| --- | --- | --- | --- |
| `id` | `uuid` | Required; no generated default | Primary key and foreign key to `auth.users.id` |
| `display_name` | `text` | Optional; null | At most 80 characters |
| `created_at` | `timestamptz` | Required; `now()` | Generated by the database |

### Projects

| Column | SQL type | Required/default | Rule |
| --- | --- | --- | --- |
| `id` | `uuid` | Required; `gen_random_uuid()` | Primary key |
| `owner_id` | `uuid` | Required | References `profiles.id`; fixed after creation |
| `name` | `text` | Required | Trimmed, 1–80 characters |
| `description` | `text` | Optional; null | At most 1,000 characters |
| `created_at` | `timestamptz` | Required; `now()` | Database-generated |
| `updated_at` | `timestamptz` | Required; `now()` | Database updates this on edits |

### Issues

| Column | SQL type | Required/default | Rule |
| --- | --- | --- | --- |
| `id` | `uuid` | Required; `gen_random_uuid()` | Primary key |
| `project_id` | `uuid` | Required | References `projects.id`; fixed after creation |
| `title` | `text` | Required | Trimmed, 1–160 characters |
| `description` | `text` | Optional; null | Plain text, at most 5,000 characters |
| `status` | `text` | Required; `'todo'` | `todo`, `in_progress`, or `done` |
| `priority` | `text` | Required; `'medium'` | `low`, `medium`, or `high` |
| `assignee_id` | `uuid` | Optional; null | References `profiles.id`; must equal the project owner when set |
| `due_date` | `date` | Optional; null | Calendar day, not a timestamp |
| `created_at` | `timestamptz` | Required; `now()` | Database-generated |
| `updated_at` | `timestamptz` | Required; `now()` | Database updates this on edits |

### Deletion

| Foreign key | Delete action | Result |
| --- | --- | --- |
| `profiles.id -> auth.users.id` | `ON DELETE CASCADE` | Removing an Auth account removes its profile |
| `projects.owner_id -> profiles.id` | `ON DELETE CASCADE` | Removing a profile removes its projects |
| `issues.project_id -> projects.id` | `ON DELETE CASCADE` | Removing a project removes its issues |
| `issues.assignee_id -> profiles.id` | `ON DELETE SET NULL` | Removing an assignee clears the assignment on any surviving issue |
